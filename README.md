# RouteX Transportation — многостраничный сайт с AI-чатом

```
routex-site-v2/
├── index.html      ← Главная (hero + мгновенная квота, why, услуги, флот, индустрии)
├── services.html   ← Услуги (Ground Expedite, Dedicated, High-Value + флот)
├── drivers.html    ← Водители: полная анкета на работу (application)
├── about.html      ← О компании: миссия, ценности, индустрии
├── contact.html    ← Контакты + форма
├── styles.css      ← Общие стили (один файл на весь сайт)
├── app.js          ← Общая логика: шапка, футер, формы, AI-чат (внедряются на все страницы)
├── api/
│   └── chat.js     ← Serverless-функция AI-чата (Vercel)
└── README.md
```

Шапка, футер и чат живут в `app.js` — правишь один раз, меняется на всех страницах.

## Как работает AI-чат и передача человеку

1. **AI отвечает сам.** Посетитель пишет в чат (кнопка внизу справа на любой странице) → браузер шлёт запрос на `/api/chat` → функция на Vercel обращается к Anthropic API → ответ появляется в чате. Твой API-ключ хранится на сервере (переменная окружения), посетители его не видят. AI знает услуги, флот, покрытие, условия для водителей и направляет людей на нужные страницы.

2. **«Talk to a human» — передача живому человеку.** Под полем ввода есть кнопка: посетитель оставляет имя и телефон/email → **вся переписка + контакты отправляются на info@routextransportationllc.com** → ты видишь письмо с темой «CHAT HANDOFF» и перезваниваешь. AI сам предлагает эту кнопку, когда речь заходит о точных ценах или сложных запросах. Тебе НЕ нужно дежурить на сайте — заявки приходят на почту.

3. **Хочешь отвечать в чате в реальном времени?** Тогда позже подключим Crisp или Tawk.to (бесплатные, есть приложение оператора для телефона). Текущая схема «AI + заявка на почту» работает 24/7 без твоего участия.

⚠️ Чтобы переписка чата и формы приходили на почту АВТОМАТИЧЕСКИ (а не через почтовый клиент посетителя), настрой Formspree — см. раздел «Формы» ниже. Это займёт 5 минут и сильно рекомендуется.

## Деплой на свой домен (Vercel, ~15 минут)

1. **GitHub**: github.com → New repository → «uploading an existing file» → загрузи ВСЁ содержимое папки → Commit.
2. **Vercel**: vercel.com → вход через GitHub → Add New → Project → выбери репозиторий → Deploy. Настройки не трогай.
3. **Ключ для чата**: Settings → Environment Variables → `ANTHROPIC_API_KEY` = ключ с console.anthropic.com → Redeploy.
4. **Домен**: Settings → Domains → Add → введи домен. Внеси у регистратора (Squarespace: Domains → твой домен → DNS):
   - Удали старые A-записи `@` (198.x.x.x) и CNAME `www` от Squarespace. MX/TXT не трогай — это почта.
   - Добавь: A-запись `@` → `76.76.21.21`, CNAME `www` → `cname.vercel-dns.com` (точные значения — на экране Vercel).
5. Подожди 10–30 минут. SSL выпустится сам.

## Формы (квота, контакты, анкета водителя, передача чата)

По умолчанию — режим **mailto**: открывается почтовый клиент посетителя с готовым письмом на info@routextransportationllc.com.

Рекомендуемый режим — **Formspree** (заявки падают на почту автоматически):
1. formspree.io → создай форму → скопируй endpoint `https://formspree.io/f/xxxxxxx`.
2. В `app.js` (вторая строка настроек) вставь его: `const FORMSPREE_ENDPOINT = 'https://formspree.io/f/xxxxxxx';`
3. Закоммить в GitHub — Vercel передеплоит сам.

Каждая заявка приходит с темой письма по типу: Quote request / Contact form / Driver application / CHAT HANDOFF.

## Что менять под себя

- Телефон, email, адрес — константы в начале `app.js` (PHONE_DISPLAY, PHONE_TEL, CONTACT_EMAIL) + продублированы в `api/chat.js` (SYSTEM_PROMPT) и в meta-тегах страниц.
- Тексты страниц — прямо в соответствующих .html.
- Знания AI-ассистента — `api/chat.js` → SYSTEM_PROMPT.
